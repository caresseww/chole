床旁触发：什么样的黄疸今天必须行动

一句话主线：先定义 → 再分层 → 抢胆道闭锁（BA）手术时间窗。胆汁淤积处理的中心不是"退黄"，是别错过 Kasai 窗口——窗口以天计，不以月计。

⚡ 一条铁律
经皮胆红素和肉眼观察无法区分结合 / 未结合——凡触发线内黄疸，第一张化验单就是 TB + DB（分离胆红素）。白陶土便 + 尿色深 = 当天走 BA 路径。

六类触发：见到就启动流程任何一条即算

触发为什么
足月儿 >14 天 / 早产儿 >21 天仍黄生理性黄疸的时间线已经走完
黄疸退而复现不是"反复"，是结合胆红素升高的经典信号
白陶土便（浅黄/灰白/陶土色）或尿色深黄染透尿布 最紧急当天开分离胆红素，按 BA 路径走
生后 5 天内 DB >0.3–0.4 mg/dL（5.1–6.8 μmol/L）或 >10% TB早期预警线，低于常规阈值即应怀疑、复查
黄疸 + 病容：反应差、发热或体温不稳、肝大、出血点感染 / 代谢病方向
黄疸 + 特殊体征：白内障、特殊面容、瘙痒抓痕、心脏杂音直奔对应病因（页④）
⚠️ 白陶土便 · 第一紧急信号
正常婴儿便黄 / 绿；浅黄、灰白、陶土色即异常。要亲手掀开尿布看最靠近肛门那一段——家长描述和手机照片都不可靠，医生亲自看粪便比任何描述都重要。尿色深提示结合胆红素升高（未结合胆红素不经肾小球滤过，不会染黑尿）——"黄 + 尿深 + 便白"三联，按 BA 路径走。

第一小时做五件事

  • 亲手看大便和尿。对照大便比色卡记录颜色——比色动作 30 秒，但它决定方向。
  • 开 TB + DB（分离胆红素）。不分离，一切后续无从谈起。
  • 同步抽血：肝功（GGT / TBA / ALT / AST / AFP）+ 空腹血糖血脂 + 凝血 + 甲功。AST≫ALT+高 AFP 指向 NICCD，反复低血糖指向全垂体 / 代谢病；凝血异常即补维生素 K₁，不等结果复看。
  • 达标者当天预约空腹 4h + 餐后超声、送 MMP-7。超声医嘱写明："检查前禁食 4h，先空腹扫胆囊，喂奶后再扫餐后收缩"——没有空腹准备，胆囊评估作废。
  • 病容者按脓毒症 + 先天感染路径并行：血 / 尿培养。UTI / 脓毒症可以黄疸为唯一首发表现，不等"明确感染灶"才查尿。
🚨 立即呼叫上级 / 外科的情况
  • 白陶土便 + 任何支持 BA 的证据（三角征 / 胆囊异常 / GGT>500 / MMP-7 升高）→ 当天消化 / 外科转诊，不等全套结果
  • 凝血异常 / 任何出血表现 → 维生素 K₁ + 上级
  • 顽固性低血糖 + 淤胆 → 内分泌 / 代谢会诊（全垂体功能低下可仅此表现）
  • 黄疸伴病容 / 发热 → 脓毒症路径同步启动
  • Kasai 术后 3–6 个月 TB 仍 >100 μmol/L → 肝移植评估

阈值与一线检查

先定义"达标"，再列必做清单——达标即进入 BA 路径，未达标按生理性 / 母乳性随访。

📋 医嘱与准备要点
  • 超声必须禁食 4h + 餐后复查——餐后收缩率是 BA 超声评估的一半
  • MMP-7 送检时注明日龄——0–30 天新生儿要用更高的分层切点（页③）
  • 凝血异常先补维生素 K₁
  • 低血糖反复者留血糖 + 同步胰岛素 / 代谢筛查标本
  • 检查并行开、并行做，不要串行等结果——BA 的窗口以天计

紧急排除胆道闭锁（BA）

BA 占可识别病因 25–40%，是最常见的可识别病因；肝门纤维块进行性闭塞胆道，Kasai 手术时机直接决定自体肝生存率。

👀 一眼线索
一般状况好、体重正常、仅黄疸 + 白陶土便 = 高度警惕 BA。第一动作不是退黄，是抢时间排除 BA。

🚨 时间窗与预后数据
加拿大：<30 天 vs >91 天 Kasai，10 年以上自体肝生存 49% vs 15%；日本：<30 天组 15 年自体肝生存 88.9%，30–45 天最佳，>90 天显著下降。但日龄不是绝对禁忌——大日龄（92–157 天，中位 109 天）手术仍有术后 1 年自体肝生存 ~68%、退黄率 68%。不要因等待逐项检查而错过窗口。

床旁动作

  • 空腹 4h + 餐后超声（三角征 / 胆囊 / 餐后收缩率）+ MMP-7（注明日龄）+ GGT，并行完成
  • 高度怀疑 → 当天外科转诊，术中胆道造影金标准、可同期 Kasai；力争 ≤45 天
🩺 术后随访（住院医最常接手的部分）
术后反流性胆管炎发生率 ~51.5%，与自体肝衰竭风险升高相关（HR ~3.6）——发热 + 胆红素回升 / 大便颜色变浅 = 胆管炎，立即抗生素。术后 3–6 个月 TB 仍 >100 μmol/L → 尽快肝移植评估。

GGT/TBA 分层与病因速查

判别核心就一个：GGT。先用 GGT / TBA 把方向分成三层，再按病因卡定向。

感染（CMV / UTI / 脓毒症等）~12% · 可治

内分泌（甲低 / 全垂体功能低下）~5% · 最易漏
线索严重胆汁淤积 + 顽固性低血糖 = 先查垂体；全垂体可仅表现为淤胆 + 低血糖，早期其他表现可不明显 动作TSH / FT4 · 空腹血糖（低血糖 + 淤胆 → 垂体激素全套，请内分泌会诊） 转归激素替代后淤胆多随之缓解
NICCD 希特林缺陷换配方就是治疗
线索圆胖脸 + 低血糖 + 低白蛋白 + AST≫ALT + AFP 异常升高 + 凝血异常 + 高血氨 + 瓜氨酸升高 动作血氨 + 氨基酸谱（瓜氨酸）+ AFP + 凝血；确诊前先无乳糖 + 强化 MCT 配方——等基因结果再换就晚了 转归多数婴儿期后随代谢成熟缓解，预后好；延误可发生严重代谢危象

TPN 相关 / NTCP 缺陷 / 特发性

红线 · 陷阱 · 随访

先记禁区，再谈诊治——这条路径上最贵的错误都是"想当然"。

五大红线

1BA 未排除前不用 UDCA——胆道完全梗阻时利胆药不仅无益，还可能加重淤胆。"先利胆退黄"是这条路径上最经典的错误第一反应。
2CMV 单独阳性 ≠ 病因——需宿主 + 多系统证据（血小板减少、听力损伤、小头、脑室周围钙化、间质性肺炎）。CMV 阳性的白陶土便患儿，照样可能是 BA；单凭 IgM/DNA 阳性归因会延误手术或特殊配方。
3一次超声 / MMP-7 阴性 ≠ 排除 BA——<30 天婴儿三角征敏感度下降、观察者间差异大；MMP-7 新生儿要用 ~28 ng/mL 分层切点，用成人切点判读会漏。临床高度怀疑时仍应外科探查。
4不要因等待逐项检查错过窗口——检查并行开、并行做；临床高度怀疑时外科会诊提前。Kasai 窗口以天计（<30 天 vs >91 天：10 年自体肝生存 49% vs 15%）。
5不要因为日龄大就放弃 Kasai——大日龄（92–157 天，中位 109 天）手术仍有术后 1 年自体肝生存 ~68%、退黄率 68%；>90 天效果差但不是绝对禁忌。

经典陷阱

  • 经皮胆红素 / 肉眼无法区分结合与未结合——凡触发线内黄疸，第一张单子就是分离胆红素
  • UTI / 脓毒症可仅以黄疸起病——没有"明确感染灶"也要查尿
  • 全垂体功能低下可仅表现为淤胆 + 顽固低血糖——早期其他表现可以不明显
  • 医生亲自看粪便 > 家长描述 / 照片——白陶土便的判断差之毫厘谬以千里
  • 空腹超声没禁食 4h = 胆囊评估作废——餐后收缩率是 BA 超声评估的一半
  • 特发性 / 新生儿肝炎是排除性诊断——先排完 BA 与可治病因，再贴这个标签

随访节奏

当天
（达标住院）
一线检查 + 空腹 4h / 餐后超声 + MMP-7 并行完成；高度怀疑 BA 者当天外科 / 消化会诊；每日查房记录大便颜色（照片）+ 尿色，胆红素趋势以 DB / TB 为主
住院期间
营养支持（能量 130–150% + MCT + 脂溶性维生素）；凝血异常随访维 K₁ 效果；低血糖者持续监测；病因确诊即启动针对性治疗
门诊
（未达标）
1–2 周内复查 TB + DB；家长大便比色卡宣教 + 大便颜色照片随访；持续 >14 / 21 天仍黄或便色变浅 → 立即回院走达标流程
BA 术后
警惕反流性胆管炎（~51.5%，HR ~3.6 关联自体肝衰竭）：发热 + 胆红素回升 / 大便变浅 → 立即抗生素；术后 3–6 个月 TB 仍 >100 μmol/L → 肝移植评估
病因治疗
NICCD 配方调整后复查肝功 / 血糖 / 凝血；CBAS 按尿胆汁酸谱调药；PFIC2 建立肿瘤监测；Alagille 瘙痒管理；内分泌病激素替代后复查淤胆与血糖
出院宣教
大便颜色拍照记录 + 脂溶性维生素续方 + 明确复诊节点——大便颜色变浅是复发 / 进展的最敏感家庭信号
核心八条
  1. 触发线——足月 >14 天 / 早产 >21 天仍黄、退而复现、白陶土便：今天查分离胆红素
  2. 经皮 / 肉眼盲区——无法区分结合 / 未结合，是延误 BA 最常见原因
  3. 达标（DB >1 mg/dL 或 DB/TB >20%）第一动作不是退黄，是抢 BA
  4. BA 两件套——空腹 4h + 餐后超声（三角征 / 胆囊收缩率）+ MMP-7（新生儿切点 ~28）；GGT>500 高度提示
  5. GGT/TBA 三层分流——高 GGT 想梗阻；不高 + TBA 高想 PFIC；不高 + TBA 低想 CBAS
  6. UDCA 红线——BA 未排除 / 胆道完全梗阻禁用
  7. 两个"≠"——CMV 阳性 ≠ 病因；一次超声 / MMP-7 阴性 ≠ 排除 BA
  8. 窗口以天计——Kasai 力争 ≤45 天；<30 天手术 15 年自体肝生存 ~89%；大日龄不是绝对禁忌
终极口诀：两周三周黄不退，亲手看便看尿；分离胆红素过线，先抢闭锁再退黄；GGT 高低定方向，熊去氧胆酸先别碰；CMV 阳性别定因，大便颜色天天看。
